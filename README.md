# KW Handyman Services

Website I built for KW Handyman Services, a handyman business serving Kitchener, Waterloo, Cambridge and Guelph.

It's a single static page (HTML, CSS and vanilla JavaScript, no framework) with the business's services, why-us section, reviews, service areas, an FAQ and a free-estimate form.

## What I focused on

- **Local search.** Title and meta description written around the services and cities customers actually search for, Open Graph tags for link previews, and `HomeAndConstructionBusiness` structured data so Google can show the business details.
- **Getting calls.** Click-to-call and the estimate form sit near the top and again at the bottom of the page.
- **Mobile first.** Most visitors come from a phone, so the layout is built for small screens and scales up.

## Running it

Open `index.html` in a browser. There's no build step, so any static host (Cloudflare Pages, GitHub Pages, Netlify) can serve the repo root as-is.
